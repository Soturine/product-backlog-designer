# /pbd

Preferred umbrella agent entrypoint (design-stage contract). Ordinary language is equally valid. Read [SKILL](../SKILL.md) and [interaction contract](../docs/usage.md), resolve the user's goal and selected sources, execute applicable internal procedures without asking for command chaining, produce the default report and canonical JSON. If an Azure target is requested, prepare a local package; remote writes require a separate approved exact plan. Delegate to specialized [commands](../docs/commands.md) internally. Do not pretend unavailable runtime functions have executed.
