# /pbd

Umbrella entrypoint; ordinary language is equally valid. Follow [SKILL](../SKILL.md) and [orchestrator procedure](../procedures/orchestrator.md): resolve intent and explicitly selected sources, run `pbd start`, coordinate one reader per source, reconcile claims, design, obtain an independent review, `pbd finalize`, then report the result with failing/blocked gates, questions and limitations. Generation, audit, comparison, refinement, check, clarify, profile, planning and ADR/source evolution are implemented on local files; publication exists only against a local mock — say so instead of simulating a real publication. Never contact a tracker.
