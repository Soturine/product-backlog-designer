# Example reports (synthetic)

Fixture reproductions built by `python tools/build_examples.py` from the test-suite payloads of a
fictional community-garden domain. They are not agent-led executions and carry no real data.

- [generation](generate/report.html)

- [comparison of two backlogs](compare/report.html)
