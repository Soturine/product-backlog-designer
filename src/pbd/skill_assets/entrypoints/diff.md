# /pbd-diff

`pbd evolve diff --old <dir with previous versions> --new <dir with new versions> --source <selector> ... --out evo/` compares the selected sources member by member after the same text extraction readers use. Each member is `identical`, `text_equivalent` (equal extracted text after whitespace/case/punctuation normalisation — **not** proof of an administrative change: figures, layout, drawings and non-text content are not compared, so `needs_agent_review` is set and you compare the originals natively), `content` (with line hunks), `added` or `removed`. The runtime never decides what a content change means: read the new version as a reader would and decide in an evolution proposal ([/pbd-adr](adr.md)).
