# /pbd

Umbrella entrypoint; ordinary language is equally valid. Follow [SKILL](../SKILL.md) and [orchestrator procedure](../procedures/orchestrator.md): resolve intent and explicitly selected sources, run `pbd start`, coordinate one reader per source, reconcile claims, design, obtain an independent review, `pbd finalize`, then report the result with failing/blocked gates, questions and limitations. Generation, audit, comparison, refinement, check, clarify, profile, planning (`pbd plan`), source/ADR evolution (`pbd evolve`) and the FTD handoff (`pbd handoff ftd`) work on local files; Azure publication exists only against a local mock (`pbd azure`). Never contact a tracker.
