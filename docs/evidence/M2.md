## What M2 implements
- **Import** (`pipeline/importer.py`): PBD backlog, `pbd.import` JSON, CSV; unknown work-item types fail closed unless mapped; native IDs, raw description and acceptance text preserved; HTML lists, tables, Gherkin and lines become criteria; orphan parents noted, never invented.
- **Audit** (`--mode audit --baseline`): reading and claims as in generation; the baseline becomes the design stage with `origin: imported` and no invented trace; the independent review contract audits it; gates report the baseline as it is.
- **Compare** (`--mode compare --baseline A --baseline B`): one shared inventory; per-side dispositions; every item/criterion of both reviewed; many-to-many mappings with relation, cardinality and differences; unmatched/unsupported derived; no winner, score or pair gates.
- **Refine**: proposal → digest-bound plan with before/after and Markdown diff → apply only approved keys; no deletion; forbidden fields refused; confirmed values need claims; stale base/plan is a conflict; changed items return to draft.
- **Check / clarify / profile**: structural health without sources (explicitly scoped), decisions waiting, observed conventions with an unverified draft profile; execution profiles economical/balanced/rigorous by capability tier.
- **Report**: rebuilt information architecture, design system, motion and offline i18n (pt-BR/en/es, 437 keys, parity tested) — see [reporting](../reporting.md).
