# PRD — Mutirões de Limpeza: inscrições (fictício)

1. O participante se inscreve em um mutirão informando nome e tamanho de camiseta.
2. A taxa simbólica de inscrição é paga pelo gateway de pagamentos parceiro.
3. A inscrição só é confirmada após a confirmação do pagamento.
4. O organizador vê a lista de inscritos confirmados por mutirão.
5. O sistema deve ser rápido.
