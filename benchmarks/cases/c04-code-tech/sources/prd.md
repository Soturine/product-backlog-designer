# PRD — Armários de Retirada de Encomendas do Condomínio (fictício)

RF1 Quando uma encomenda é depositada, o morador recebe um código de retirada de 6 dígitos.
RF2 O código de retirada expira 72 horas após o depósito.
RF3 Após 3 tentativas com código incorreto, o armário fica bloqueado por 10 minutos.
RF4 Encomenda não retirada até a expiração do código é devolvida à portaria e o morador é avisado.
RF5 O porteiro consulta quais armários estão ocupados.
