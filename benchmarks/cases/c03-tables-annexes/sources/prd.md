# PRD — Cadastro de Voluntários da ONG (fictício)

O cadastro reúne voluntários para ações da organização. Os requisitos estão na tabela abaixo; as regras de validação estão no anexo.

| ID | Requisito | Prioridade |
|---|---|---|
| RQ1 | O voluntário se cadastra informando nome, e-mail e telefone. | Alta |
| RQ2 | O coordenador aprova ou recusa cadastros pendentes. | Alta |
| RQ3 | Voluntário recusado recebe e-mail com o motivo da recusa. | Média |
| RQ4 | O voluntário escolhe áreas de interesse entre as áreas cadastradas pelo coordenador. | Média |
| RQ5 | O coordenador exporta a lista de voluntários aprovados em CSV. | Baixa |
