# PRD — Bazar Beneficente: agendamento de doações (fictício)

1. O doador agenda a entrega de doações escolhendo data e turno.
2. Cada doador pode agendar no máximo 3 entregas por mês.
3. Itens eletrônicos não são aceitos.
4. O voluntário confirma o recebimento e o sistema gera um recibo para o doador.
5. O doador pode remarcar uma entrega até 1 dia antes da data agendada.
